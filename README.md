## Описание плагина

Плагин предназначен для автоматического создания файла **CMakeLists.txt** в проектах на языке C++.

Возможности плагина:
- Поиск всех файлов исходного кода с расширением .cpp и заголовочных файлов .h, .hpp во всех папках проекта.
- Проверка наличия функции main для определения исполняемых программ.
- Поиск директив #include для выявления связей между файлами.
- Построение графа зависимостей и сортировка файлов.
- Разделение файлов проекта на библиотеку (add_library) и исполняемые файлы (add_executable).
- Связывание исполняемых файлов с библиотекой (target_link_libraries).
- Добавление путей к заголовочным файлам (target_include_directories).
- Запрос подтверждения перед перезаписью, если **CMakeLists.txt** уже существует.
- Автоматическое открытие созданного файла в редакторе.

## Как устроен плагин

Плагин работает внутри VS Code и активируется при вызове команды (Cmd+Shift+P -> CMake Generator: Сгенерировать CMakeLists.txt).

В файле **package.json** зарегистрирована команда для запуска плагина.

Для работы используются стандартные возможности VS Code:
- поиск, чтение и запись файлов на диск (vscode.workspace.fs);
- показ всплывающих окон и предупреждений (vscode.window);
- открытие созданного файла в окне редактора (vscode.window.showTextDocument).

## Структуры данных и алгоритм

1. ProjectFile — структура данных с информацией о каждом найденном файле: путь, имя, расширение, признак наличия функции main, список заголовочных файлов из #include.
2. DependencyGraph — граф зависимостей на основе списка смежности (Map<string, Array<string>>).
3. Топологическая сортировка — обход графа в глубину (DFS) для упорядочивания файлов и исключения циклов.

## Структура файлов плагина

- **src/main.ts** — точка входа плагина, регистрация команды, проверка открытой папки и открытие готового файла.
- **src/fileScanner.ts** — рекурсивный поиск файлов .cpp и .h.
- **src/filesParser.ts** — чтение файлов, поиск директив #include и функции main.
- **src/CreateGraph.ts** — построение графа зависимостей, сортировка и разделение на библиотеки и исполняемые файлы.
- **src/cmakeGenerator.ts** — составление текста файла **CMakeLists.txt**.
- **sample_project/** — демонстрационный проект C++ для проверки работы плагина.

## Инструкция по запуску

### 1. Установка и компиляция

```bash
npm install
npm run compile
```

### 2. Запуск плагина в режиме отладки

1. Открыть папку плагина в VS Code.
2. Нажать клавишу F5.
3. Откроется новое окно Extension Development Host.

### 3. Проверка работы плагина

1. В открывшемся окне открыть папку **sample_project/**.
2. Нажать комбинацию Cmd+Shift+P (или Ctrl+Shift+P).
3. Найти и запустить команду:
```
CMake Generator: Сгенерировать CMakeLists.txt
```
4. В папке создастся и сразу откроется файл **CMakeLists.txt**.

### 4. Проверка компиляции проекта

Для проверки работоспособности сгенерированного файла выполнить в терминале:

```bash
cd sample_project
cmake -B build
cmake --build build
./build/main
```
